# syncplay — 双机同步起播

两台电脑各跑一份，**演出时不用联网**，靠同一张时间表和系统时钟对齐：
默认每 10 秒就有一个时点（`…:00`、`:10`、`:20`…），两台在同一个时点同时开始；
时点间隔也可以在界面上改成 15 或 20 秒。

需要 Python 3.8+。

## 一、先装两样东西

**Python**：安装时勾选 **Add Python to PATH**。

**mpv**（视频端用），在 PowerShell 里执行：

```powershell
winget install -e --id shinchiro.mpv
```

> 不要用 `winget install mpv`——它会同时匹配到 `shinchiro.mpv` 和 `MPV.NET` 两个包，让你二选一。
> 装完 **关掉 PowerShell 重新开**，执行 `mpv --version`，能看到版本号才算成功。

## 二、双击就能用

把下面 4 个文件放在**同一个文件夹**里：

```
FL端.pyw
视频端.pyw
syncplay_gui.py
syncplay.py
```

另有三个可选文件，需要时一起放进去：

```
对时.pyw          # 独立对时校准工具（需要 calibrate.py）
calibrate.py
视频端-精简.pyw    # 只有右下角小浮窗的精简版
```

- 舞台电脑双击 **FL端.pyw**
- 视频电脑双击 **视频端.pyw**

不用开命令行，不会弹黑框。

视频端第一次打开时，点 **“选择视频…”** 选一个视频文件。选完会自动加载并暂停在首帧，之后会记住（存在 `last_video.txt`），下次打开直接可用。

视频端启动时会**先把 mpv 拉起来**（投影/副屏会先黑屏待命），选视频只是往这个 mpv 里换片，所以是瞬间的；第一次打开时那几秒的全屏切换已经提前到这里了。

关闭界面时，如果还没起播，会把这个空 mpv 一起关掉；已经起播则保留播放。

视频端右上角还能切 **输出屏幕**：`0` 是主屏，`1` 是扩展屏/投影。选一次会记住（存在 `last_screen.txt`）。

## 三、界面怎么操作

界面一直显示两个时点：

- **下一时点**：最近的一个 `:00` / `:20` / `:40`
- **下下个时点**：再下一个

按 **Enter 就位**，倒计时到 0 自动开始；按 **Esc 取消**。

一次起播结束后，按 **Esc** 复位，再按 Enter 就能等下一轮，不用重开程序。

视频端点 Enter 就位后，主窗口会最小化到任务栏（单屏时），**屏幕右下角**出现一个透明小浮窗：

- 上行是时间码（`分:秒` 标红），下行是倒计时秒数
- 左边有个小图标：**▶** = 等你按 Enter，**时钟** = 正在倒计时
- 待就位时也会显示，方便随时瞄一眼下一个时点；起播后自动消失

点一下浮窗，或在浮窗上按 **Enter / Esc**，就能恢复主界面（按任务栏的 Syncer 也一样）。

- 最后 3 秒状态变成“准备”，倒计时变黄。
- 如果下一时点已经来不及（不足 3 秒），会自动跳到再下一个，卡片直接换成新时点，并标注“X 秒内可用”。
- 当前选中的时点会标一个“目标”。
- 窗口默认置顶，不会挡住 FL 的操作。

> 两台要**一起按 Enter**，按完各自看一眼卡片上的目标时刻是否一样；不一样就都按 Esc 重来。
> 两台不需要通信，只要时钟准、按的时机相近，选中的就是同一个时点。

## 四、时间表是怎么对齐的

时间表就是每分钟的 `:00`、`:20`、`:40`。程序取“下一个至少 3 秒之后的格子”作为目标 T，两台各自在 T 时刻触发。

所以两台的系统时钟要准。开演前两台都执行一次（管理员权限）：

```powershell
w32tm /resync
```

服务没开就先 `net start w32time`。界面底部会显示时钟偏差，超过 50ms 会标 ⚠。

## 五、开演前检查

- [ ] 两台都 `w32tm /resync`，界面时钟偏差在 ±50ms 内
- [ ] 关掉自动更新、通知、休眠、屏保
- [ ] FL 已停止，播放头在起点
- [ ] 视频端已选好视频，状态是“待就位”
- [ ] 两台一起按 Enter，核对目标时刻一致
- [ ] 准备好手动播放的备用方案

## 六、校准（很重要）

1. 两台同时播一个“白闪 + beep”的测试片（或用手机 240fps 慢动作拍）。
2. 量出实际偏移，例如视频比 FL 晚 80ms。
3. 给视频端填补偿：主界面顶部有 **`补偿 [ ] ms`** 输入框，填 `-80`（负数 = 提前触发），回车即刻生效，并自动记住（`last_offset.txt`）。
4. 更省事的办法：双击 **`对时.pyw`**，两台各开一个窗口，跟着节拍拖滑块对齐；补偿会写进 `last_offset.txt`，播放端待就位时一秒内自动读取。

> 命令行方式同样可以，加 `--offset-ms -80`。

## 七、命令行版（高级用法）

参数和界面版通用。需要 `--at` 钉死时刻、`--offset-ms` 补偿时用它。

**钉死时刻**（最稳，正式演出推荐，两台填同一个时间）：

```powershell
python syncplay.py --role fl --at 20:31:00
python syncplay.py --role video --player mpv --file "E:\show\video.mp4" --at 20:31:00
```

**带补偿**：

```powershell
python syncplay_gui.py --role video --player mpv --file "E:\show\video.mp4" --offset-ms -80
```

也可以直接用 `syncplay.py`（无界面），参数完全一样：

```powershell
python syncplay.py --role fl
python syncplay.py --role video --player mpv --file "E:\show\video.mp4" --screen 1
```

> `--at` 只在 `syncplay.py` 里生效；图形界面按 `:00/:20/:40` 时间表工作。

## 八、FL 更稳的触发方式：MIDI

模拟按键怕焦点被抢，MIDI 不会。

1. 装 [loopMIDI](https://www.tobias-erichsen.de/software/loopmidi.html)，建一个虚拟端口。
2. FL → Options → MIDI Settings → Refresh，在 Input 列表启用这个端口。
3. 右键 FL 的 Play 按钮 → Link to controller → 按一下那个 MIDI 音符。
4. 启动时加端口名：

```powershell
python syncplay_gui.py --role fl --fl-midi-port "loopMIDI Port 1"
```

> 双击版默认用按键（Space）；需要 MIDI 时用命令行方式启动。

## 九、播放器

| 播放器 | 参数 | 说明 |
|---|---|---|
| mpv（推荐） | `--player mpv` | 提前加载暂停，IPC 取消暂停，延迟最小 |
| VLC | `--player vlc` | `--start-paused` + rc 接口 |
| WMP | `--player wmp` | 需要 `pip install pywin32`，精度最差，不推荐 |

mpv 安装见第一节；图形界面会自动在 PATH 和常见安装位置里找它。

## 十、更多功能（v1.4.0）

**播放列表**：点「播放列表…」一次加入多个视频，开演后逐条播放；每条播完停在最后一帧、自动复位等下一个时点；**全部播完后按 Esc 直接退出程序**。

**拉伸全屏**：勾选「拉伸全屏」后 mpv 用 `--keepaspect=no` 铺满（不保持宽高比），勾选状态会记住。

**结束播放**：主界面底部右侧的「结束播放」按钮（鼠标专用，无快捷键），点击会二次确认；确认后 mpv 淡出关闭、程序退出。

**多屏适配**：视频输出到副屏时，主界面保持显示、右下角不再叠时间码（主界面就在眼前）；输出到主屏时照旧隐藏主界面、显示时间码。

**精简模式**：双击 `视频端-精简.pyw`，只有右下角那个透明小浮窗，没有主界面。

**时钟偏差自动补偿**：启动时用 SNTP 测本机与 NTP 的偏差，超过 40ms 就自动修正触发时刻（状态栏显示“已自动补偿 ±X ms”），并把结果存进 `last_clock.txt`；**下次启动如果没联网，会自动沿用上次测到的偏差**（状态栏显示“离线缓存 MM-DD · 已补偿”）。两台不再强制需要 `w32tm` 对时，但保留对时会更准。

## 十一、参数速查

| 参数 | 默认 | 说明 |
|---|---|---|
| `--role` | none | fl / video / both / none |
| `--grid` | 0,10,20,30,40,50 | 每秒的时点网格（默认每 10 秒一个时点） |
| `--at` | — | 手动指定 HH:MM:SS（仅 `syncplay.py`） |
| `--in` | — | N 秒后触发（排练） |
| `--offset-ms` | 0 | 本机补偿，负数 = 提前 |
| `--stretch` | 关 | 拉伸画面铺满全屏（不保持宽高比） |
| `--dry-run` | 关 | 只倒计时，不碰软件 |
| `--fl-midi-port` | — | 用 MIDI 触发 FL |
| `--screen` | 记住上次 | 图形界面右上角可切；命令行不填时默认 1 |
| `--lead` | 8 / 3 | 命令行 8 秒；图形界面固定 3 秒 |
| `--log` | — | 写日志文件 |

## 十二、常见问题

- **双击后没反应**：先等 3 秒（第一次启动可能被杀软扫描）。还不行就看文件夹里的 `boot.log`：
  - 没有新的 `launcher ... start` 行 → Windows 没启动脚本。右键 `.pyw` → 打开方式 → 选 Python 安装目录里的 `pythonw.exe`，勾“始终使用”。
  - 有 `start` 但没有 `app ready` → 打开 `error.log` 看报错。
  - 有 `app ready` 但看不到窗口 → 多半被全屏程序盖住了，按 Alt+Tab 找 “Syncer”。重复双击不会开第二个，只会把已有的窗口提到前面。
- **视频端提示“找不到 mpv”**：按第一节安装，装完重开程序；或命令行加 `--mpv "完整路径\mpv.exe"`。
- **winget 说装好了，但 `mpv` 命令找不到**：它装在 `C:\Program Files\MPV Player\`，这个目录默认不在 PATH。不用管 PATH，视频端会自动找到；想让终端里也能用，把这个文件夹加到用户 PATH。
- **两台时点不一样**：两台按 Enter 的时机差了，或时钟不准。先对时，再都按 Esc 重来；正式演出直接用 `--at`。
- **FL 按键没反应**：窗口没在前台；改用 MIDI 触发。
- **投影上没有画面**：单屏自动用 0 号屏，双屏默认 1 号屏；命令行加 `--screen 0` 或 `--screen 1` 指定。
- **WMP 播完脚本一退就停**：加 `--hold`。
