用DSH做的一个小工具，可以实现背景视频和乐队表演的同步。

## 适用范围
出于种种原因无法用同一台电脑同时输出节拍器和背景视频的情况。如果不属于这种情况，建议用更简便稳定的解决方案

## 使用前提
在舞台上放一台电脑，用于放节拍器给鼓手听。舞台上的电脑和负责控制大屏的电脑都要安装此程序和Python。控制大屏的电脑要安装MPV Player。演出时，需要有人在播放视频的电脑处与舞台上的人保持通话并进行配合操作

## 优势
不依赖人手动卡拍子；可以手动调节预留的容错时间（例如设为20秒，则两边按下播放的时间误差在20秒内都可以被同步）；两台电脑不需要互相通信

## 实现原理
在电脑能联网时通过时间服务器对电脑时间进行校准。演出时，按下播放键后程序根据当前时间选择下一个起播时间，例如现在是16:03:02，设置的容错时间为20秒，则程序会在16:03:20开始播放视频/音频。程序会实时显示下一个起播时间，舞台上的人和控制视频的人通话确认两边时间相同即可。

## 需要做的准备：

### 【演出前】

- 两台电脑都要安装Python（去官网下载，安装时勾选 Add Python to PATH）
- 播放视频的电脑要安装MPV Player。在PowerShell中输入：
```powershell
winget install -e --id shinchiro.mpv
```
- 由于我用的宿主是FL Studio，所以目前只做了FL的适配。因为原理很简单，其他宿主请自行适配，不会的就装个FL。
- 在播放视频的电脑上打开视频端.pyw，选择播放视频的显示器以及是否拉伸视频到全屏，在播放列表里添加要播的视频，然后关闭程序（程序会保存选择的视频路径和各种设置）
- 默认的容错时间是10秒，如有需要可以点击右上角的“间隔10秒”进行修改。一定要保证两台电脑选择的间隔时间相同！

### 【演出时】

（每次打开程序时会尝试联网校准一次时间，如果没联网则会使用上次校准得到的补偿值，所以最好在演出时保证两端都是联网的，或者在靠近演出的时候联网校准过一次）

播放节拍器/program的电脑打开FL，运行FL端.pyw，记得在FL内把播放头拖到正确的开始位置

播放视频的电脑运行视频端.pyw

两边保持通话，准备好后通话确认下一个起播时间（我们的方案是读出时间码的后四位数字，在程序里标红了），确认一致后分别立即按下Enter。等倒计时归零后，视频和宿主中的工程就会同步开始播放。

如果播放列表中有多个视频，则每个视频结束后重复确认时间并按Enter这个流程即可。

播放完后，视频端点击“结束播放”并二次确定即可退出。注意，每次关闭程序都会将播放进度重置，即每次都会从播放列表的第一个视频开始播放。

在只有一个显示器时，本程序会将下一个起播时间以及剩余的可用按键时间显示在右下角，尽量不影响观感。如果运行视频端-精简.pyw，则不会打开程序的主窗口，而是直接进入视频的待播状态（右下角显示上述信息）。使用精简版需要提前在程序里设置好视频列表等。
