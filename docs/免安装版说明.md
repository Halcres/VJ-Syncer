# 免安装版（exe）说明

不用装 Python，解压就能用。

## 下载与解压

1. 下载 `Syncer_vX.Y.Z_win64.zip`
2. 解压到任意位置（例如 `D:\Syncer`）
   **`Syncer.exe`、`_internal\`、`mpv\` 三个必须在一起**，不能只把 exe 单独拷出来

## 双击哪个

| 快捷方式 | 作用 |
|---|---|
| `FL端.lnk` | 放节拍器 / 工程的那台 |
| `视频端.lnk` | 放视频的那台（完整界面） |
| `视频端-精简.lnk` | 只显示右下角提示，没有主界面 |
| `对时.lnk` | 对时校准工具 |

也可以直接双击 `Syncer.exe`，会弹一个小窗口让你选。

## 和源码版的区别

- **不需要安装 Python**：运行时已经打包进 `_internal\`
- **自带 mpv**（`mpv\mpv.exe`），程序会优先用它，不用另外安装；
  许可证见 `mpv\许可证说明.txt`（mpv 为 GPL）
- 配置和日志都在 exe 同目录：`playlist.txt`、`last_*.txt`、`boot.log`、`error.log`

## 第一次运行可能弹提示

Windows 可能提示「Windows 已保护你的电脑」（exe 没有代码签名）：
点 **更多信息 → 仍要运行** 即可，不是程序出错。

## 自己重新打包

在源码目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build_exe.ps1
```

- 需要：Python 3.8+，以及本机装有 mpv（默认从 `C:\Program Files\MPV Player\` 复制，可用 `-MpvDir` 指定别的路径）
- 首次运行会把 PyInstaller 下载到 `_vendor\`（不污染系统 Python）
- 产物：`dist\Syncer\` 和 `Syncer_vX.Y.Z_win64.zip`
